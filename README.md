# Свадьба Антона и Ольги — сайт-приглашение

Готовая одностраничная версия приглашения. Без сборки, без Tailwind и без сторонних JS-библиотек, кроме официального Formspree Ajax: достаточно открыть `index.html` или загрузить папку на любой хостинг.

## Файлы

- `index.html` — весь сайт (разметка, стили, скрипты).
- `map.png` — статическая карта площадки «Флора» (Яндекс.Карты).
- `README.md` — эта инструкция.

## Что уже работает

- Адаптивный дизайн под телефон, планшет и десктоп.
- Таймер обратного отсчёта до 16 декабря 2026, 17:00 (Челябинск, UTC+5).
- Программа дня и место проведения с картой.
- Кнопка «Добавить в календарь» — скачивает `.ics` с датой, временем и адресом.
- Анкета гостя: имя, присутствие, трансфер/размещение и пожелания.
- Если гость выбирает «К сожалению, не смогу», блок с трансфером скрывается и не отправляется.
- Отправка формы через Formspree Ajax без перезагрузки страницы, с сообщениями об успехе и ошибке на русском.
- Плавные появления блоков, мобильное меню, активный пункт навигации.
- Доступность: skip-link, подписи полей, `aria`-атрибуты, поддержка `prefers-reduced-motion`. Lighthouse: Accessibility / Best Practices / SEO — 100.

## Как посмотреть

1. Откройте `index.html` двойным щелчком — сайт работает локально.
2. Для проверки отправки формы лучше загрузить сайт на хостинг (см. ниже): некоторые браузеры ограничивают сетевые запросы со страниц `file://`.

## Как опубликовать

Самый простой вариант — **Netlify Drop**:

1. Откройте <https://app.netlify.com/drop>.
2. Перетащите папку `svadba` целиком.
3. Получите готовую ссылку и отправьте её гостям.

Также подойдут GitHub Pages, Vercel или любой обычный хостинг — это статические файлы.

## Интеграция Formspree

Сайт — обычная статическая HTML-страница без React и без сборщика, поэтому используется вариант **Vanilla JS (Ajax)** из документации Formspree: официальная библиотека `@formspree/ajax` подключается через CDN.

Подключение находится в конце `index.html`:

```html
<script src="https://unpkg.com/@formspree/ajax@1" defer></script>
```

Инициализация формы — в основном скрипте:

```js
formspree("initForm", {
  formElement: "#wedding-form",
  formId: "xbgggkln",
  useDefaultStyles: false,
  onSuccess: ...,
  onError: ...,
  onFailure: ...
});
```

Что это даёт:

- заявка отправляется на `https://formspree.io/f/xbgggkln` без перезагрузки страницы;
- кнопка блокируется на время отправки;
- ошибки полей подсвечиваются, а сообщения показываются на русском;
- после успешной отправки форма скрывается и показывается блок «Спасибо!»;
- при выключенном JavaScript продолжает работать обычная отправка через `action`/`method` формы.

### Если нужно заменить форму

1. Зарегистрируйтесь на <https://formspree.io>.
2. Создайте форму и укажите почту для ответов.
3. Замените ID `xbgggkln` в двух местах:
   - `action="https://formspree.io/f/xbgggkln"` у формы;
   - `formId: "xbgggkln"` в вызове `initForm`.
4. Подтвердите почту в Formspree и отправьте тестовый ответ.

Пока ID не заменён, проверьте, что заявки действительно приходят на нужную почту.

## Что заменить перед публикацией

### 1. Дата и время

Таймер:

```js
const weddingTimestamp = new Date("2026-12-16T17:00:00+05:00").getTime();
```

Событие в календаре (время в UTC: 17:00 по Челябинску = 12:00 UTC):

```js
"DTSTART:20261216T120000Z",
"DTEND:20261216T170000Z",
```

Дедлайн анкеты «до 1 декабря 2026 года» указан в тексте над формой.

### 2. Имена, адрес, площадка

Имена «Антон и Ольга» указаны в заголовке `title`, hero, подвале, письме Formspree и ICS-файле. Адрес — в блоке «Флора», в ссылке на Яндекс.Карты и в карте.

### 3. Карта

`map.png` — статический снимок Яндекс.Карт без рекламы и без API-ключа. Если адрес изменится, сгенерируйте новый снимок, например:

```
https://static-maps.yandex.ru/1.x/?ll=61.415409,55.152780&z=16&l=map&pt=61.415227,55.152726,pm2rdm&size=650,450
```

Сохраните его как `map.png`. Ссылку на Яндекс.Карты в блоке «Флора» тоже обновите.

### 4. Что можно добавить

Сейчас на сайте нет фотографий, дресс-кода и раздела про подарки — этих деталей не было в исходном тексте. Если они нужны, их стоит добавить отдельными блоками: с фотографиями пары, палитрой дресс-кода и пожеланиями по подаркам.

## Технические детали

- Шрифты: Cormorant Garamond + Inter с Google Fonts. При недоступности сети сработают системные запасные шрифты.
- Все стили и скрипты — внутри `index.html`. Внешние зависимости: Google Fonts и `@formspree/ajax`.
- В форме нет полей «меню» и «напитки» — они убраны по просьбе.
- Анимации отключаются при `prefers-reduced-motion: reduce`.
- Тёмная фактура и декоративная арка сделаны на CSS/SVG, поэтому не требуют отдельных изображений.
