# Свадьба Антона и Ольги — сайт-приглашение

Готовая одностраничная версия приглашения. Без сборки, без Tailwind и без сторонних JS-библиотек, кроме официального Formspree Ajax: достаточно открыть `index.html` или загрузить папку на любой хостинг.

## Файлы

- `index.html` — весь сайт (разметка, стили, скрипты).
- `map.png` — статическая карта площадки «Флора» (Яндекс.Карты), центрированная по метке.
- `photos/` — пять фотографий пары для блока «Наша история».
- `og-image.jpg` — превью 1200×630 для WhatsApp, Telegram и соцсетей.
- `qr-code.png` — QR-код на `https://antoniolga.ru` для печатных приглашений.
- `music.mp3` — фоновая музыка (Claude Debussy, «Clair de lune», public domain).
- `README.md` — эта инструкция.

## Что уже работает

- Адаптивный дизайн под телефон, планшет и десктоп.
- Входная страница «Вам письмо»: по клику открывается приглашение и запускается музыка.
- Блок «Наша история» с текстом и пятью фотографиями пары.
- Пасхалка: три клика по подписи «С любовью, Антон и Ольга» выпускают Добби — интерактивного сфинкса, который бегает по странице и реагирует на клики.
- Таймер обратного отсчёта до 16 декабря 2026, 17:00 (Челябинск, UTC+5).
- Программа дня и место проведения с картой.
- Кнопка «Добавить в календарь» — скачивает `.ics` с датой, временем и адресом.
- Анкета гостя: имя, телефон или Telegram (необязательно), присутствие, трансфер и пожелания.
- Если гость выбирает «К сожалению, не смогу», блок с трансфером скрывается и не отправляется.
- Анкета сохраняется в Cloudflare D1, приходит в Telegram и дублируется в Formspree.
- Фоновая музыка: запускается после открытия конверта, кнопка включения/паузы — в шапке сайта.
- Красивое OG-превью для ссылок в мессенджерах и QR-код для печатных приглашений.
- Плавные появления блоков, мобильное меню, активный пункт навигации.
- Доступность: skip-link, подписи полей, `aria`-атрибуты, поддержка `prefers-reduced-motion`. Lighthouse: Accessibility / Best Practices / SEO — 100.

### Как обновить опубликованный сайт

1. Измените файлы в папке `svadba` (например, `index.html` или `map.png`).
2. Загрузите изменения в репозиторий:
   ```bash
   git add .
   git commit -m "Update site"
   git push
   ```
   Либо загрузите файлы через веб-интерфейс GitHub.
3. GitHub Pages обновится автоматически через 1–2 минуты.

Локальная проверка: откройте `index.html` двойным щелчком. Для проверки формы лучше использовать опубликованную ссылку — некоторые браузеры ограничивают сетевые запросы со страниц `file://`.

## Анкета, Telegram-бот и Formspree

Сайт остаётся статическим, но анкета отправляется не напрямую в Formspree, а через свой адрес:

```js
const RSVP_ENDPOINT = "https://api.antoniolga.ru/api/rsvp";
```

`api.antoniolga.ru` — маленький релей на Vercel (папка [`relay/`](relay/README.md)). Он нужен потому, что в некоторых сетях `*.workers.dev` не открывается: гость обращается к своему домену, а релей передаёт запрос в Cloudflare Worker.

```
Браузер → api.antoniolga.ru (Vercel) → Worker (Cloudflare) → D1 + Telegram + Formspree
```

Что происходит при отправке:

1. Worker сохраняет гостя в базе Cloudflare D1.
2. Если анкета с таким именем уже есть, она обновляется — дублей не будет.
3. Присылает уведомление администраторам в Telegram.
4. Дублирует заявку в Formspree, чтобы сохранить привычные письма.
5. Возвращает сайту успешный ответ — форма показывает «Спасибо!» или «Ваш ответ обновлён».
6. При выключенном JavaScript срабатывает обычная отправка через `action` формы в Formspree.

Если релей или Worker недоступны, форма после 15 секунд ожидания отправляет анкету напрямую в Formspree и всё равно показывает «Спасибо!». Ответ не теряется: он придёт на почту, хотя в D1 и Telegram может не попасть.

### Telegram-бот

Бот: [@antoniolga_bot](https://t.me/antoniolga_bot)

- принимает скриншот пасхалки с кодом `DOBBY-1612`;

- `/broadcast` — рассылка всем, кто нажал Start;
- каждый день присылает CSV-бэкап, каждые 30 минут проверяет доступность сайта.

Подробная инструкция по Worker, D1 и деплою — в [`bot/README.md`](bot/README.md), по релею — в [`relay/README.md`](relay/README.md).

### Если нужно заменить форму или бота

- ID Formspree указан в `bot/wrangler.toml` (`FORMSPREE_FORM_ID`) и в `action` формы. При замене обновите оба места.
- Адрес приёма анкет меняется в `index.html` (`RSVP_ENDPOINT`). Сейчас это `https://api.antoniolga.ru/api/rsvp` — релей на Vercel, который передаёт запрос в Worker.
- Если меняется адрес Worker, обновите `WORKER_URL` в настройках проекта Vercel (по умолчанию он уже прописан в `relay/api/rsvp.js`).
- Секреты бота (`BOT_TOKEN`, `ADMIN_IDS`, `WEBHOOK_SECRET`, `SETUP_SECRET`) хранятся только в Cloudflare.

## Что заменить перед публикацией

### 1. Дата и время

Таймер:

```js
const weddingTimestamp = new Date("2026-12-16T17:00:00+05:00").getTime();
```

Событие в календаре (время в UTC: 17:00 по Челябинску = 12:00 UTC):

```js
"DTSTART:20261216T120000Z",
"DTEND:20261216T170000Z",
```

Дедлайн анкеты «до 1 декабря 2026 года» указан в тексте над формой.

### 2. Имена, адрес, площадка

Имена «Антон и Ольга» указаны в заголовке `title`, hero, подвале, письме Formspree и ICS-файле. Адрес — в блоке «Флора», в ссылке на Яндекс.Карты и в карте.

### 3. Карта

`map.png` — статический снимок Яндекс.Карт без рекламы и без API-ключа, центрированный по метке площадки. По клику на «Открыть карту» открывается полноценная интерактивная карта в Яндекс.Картах.

Встроенная интерактивная карта Яндекса требует платного JavaScript API (минимальный тариф — около 20 000 ₽/год), поэтому на сайте оставлен аккуратный статический снимок. Бесплатная альтернатива без рекламы — OpenStreetMap/Leaflet; при желании карту можно заменить.

Если адрес изменится, сгенерируйте новый снимок, например:

```
https://static-maps.yandex.ru/1.x/?ll=61.415409,55.152780&z=16&l=map&pt=61.415227,55.152726,pm2rdm&size=650,450
```

Сохраните его как `map.png`. Ссылку на Яндекс.Карты в блоке «Флора» тоже обновите.

### 4. Что можно добавить

Фотографии и история пары уже добавлены. На сайте пока нет дресс-кода и раздела про подарки — если они нужны, их можно добавить отдельными блоками: с палитрой дресс-кода и пожеланиями по подаркам.

## Технические детали

- Шрифты: Cormorant Garamond 400/500 (заголовки и акценты) + Inter 400/500 (текст и интерфейс). Единая сетка размеров, трекинга и межстрочных интервалов.
- Все стили и скрипты сайта — внутри `index.html`. Backend — Cloudflare Worker + D1. Внешние зависимости сайта: Google Fonts.
- В форме нет полей «меню», «напитки» и «помощь с размещением» — убраны по просьбе.
- Анимации отключаются при `prefers-reduced-motion: reduce`.
- Тёмная фактура и декоративная арка сделаны на CSS/SVG, поэтому не требуют отдельных изображений.
